# 股票匹配与逐句引用专项验收

这轮完成股票代码、卡片日期、周期的识别，并增加逐句引用检查。属于 RAG 调优，没有训练 embedding、reranker 或答题模型。接口和规则见 [专项说明](stock-claims.zh.md)。

生成只做四次，不重试刷分，也没有再跑全套生成 A/B。三个正例加一个阴性题只覆盖三个事件组，全部是已用过的回归题，不是独立盲测、人工审计或总体正确率。

严格标签评分是 **2/4**，与语义复核分开：一个回答多写了未获本句引用支持的后一天确认结论；另一个回答忠实引用了同一计划在另一周期卡片中的完整重述，但冻结标签仍限定原文件。保留该严格失败，不修改金标来提高分数。阴性题拒答，没有编造券商成交记录。

本轮先发现“卡片找对、段落却是‘在途’”的问题，再增加卡片数字字段的词项并重跑三个 MCP 案例；不能把早期文件命中当最终段落验收。源文、题目和原始答案留在本地私有产物中。

## 能复用什么，不能声称什么

- 股票文件名解析、“入／损”的对应、计划与交易窗口规则针对本地股票语料；换数据格式或业务需要适配。
- 逐句绑定引用、检查过期内容、把出处检查与语义复核分开，是可复用的 RAG 方法。本轮只在已列出的场景验证。
- 检查器没有调用新的大模型，也不能理解任意自然语言蕴含。复杂表格、相对时间、推导和计算可能要求补证；通过规则检查不等于结论正确。
- MCP 已提供检查入口和调用说明，宿主仍须实际调用并处理失败。没有声称任意客户端都已被强制接入。
- 股票 hybrid 仍有 1/12 漏检，而 BM25 已 12/12，下一步可针对融合排序做小范围验证。新增独立作者题、真实宿主行为与来源事实时效，比直接开始训练更值得优先验证。
